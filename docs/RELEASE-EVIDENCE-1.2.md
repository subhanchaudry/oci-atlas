# OCI Atlas v1.2 release evidence

Research cutoff and review: **2026-11-17**. Status: **release prepared; not published**. This register records documentation evidence, not OCI tenancy access, deployed functionality, regional inventory, or customer approval.

## Acceptance rule

Use current Oracle product documentation or dated release notes for operational guidance. Entries marked **Accepted — documented available** below have an affirmative available/supported statement or an operational product page, with no preview or limited-availability label for the included capability in the reviewed sources. This is feature-specific evidence, not a claim that every feature in the product or every region is GA. No region, capacity, entitlement, or configuration is inferred from a press announcement. Preview dependencies and conflicting claims are deferred.

Each row applies only to the scope and restrictions stated. Sources were reviewed on the date shown. Recheck accepted evidence before publishing if publication occurs later; the cutoff is not a promise of future availability. The source register also lives beside each packaged guide in its Sources section.
