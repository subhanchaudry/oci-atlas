# Start with OCI Atlas

Install the plugin using the [installation guide](INSTALL.md), then open a new conversation.

The [packaged getting-started guide](../plugins/oci-atlas/skills/oci-atlas/references/getting-started.md) covers explanations, architecture design, scoped resource inspection, troubleshooting and operational tasks. It is available directly to the assistant after installation.

Try: “Use OCI Atlas to help me choose a path for my workload. Start with a design and reuse suitable existing services.”

Continue with [workload selection](../plugins/oci-atlas/skills/oci-atlas/references/workload-selection.md), [illustrated walkthroughs](../plugins/oci-atlas/skills/oci-atlas/references/walkthroughs.md), or the [application examples](../examples/README.md).

Knowledge questions require no OCI login. Resource operations use your existing tools, authenticated identity and OCI permissions. Keep passwords, tokens, wallets and private keys in their normal authentication mechanisms.

For this release, start with [what changed in v1.2](WHATS-NEW-1.2.md). Atlas supplies guidance; it adds no execution tools or MCP endpoint. Ask it to identify documented availability, regional/configuration constraints, and missing evidence before recommending a new service. The prepared v1.2 tag and download links become available only after publication.
