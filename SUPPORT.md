# Get help with OCI Atlas

Use [GitHub Issues](https://github.com/subhanchaudry/oci-atlas/issues) for installation questions, unclear guidance, and suggested improvements. OCI Atlas is maintained as a community project.

## Find the right starting point

- Installing or updating: follow the [installation guide](docs/INSTALL.md).
- Looking for a service or workflow: browse the [content catalog](docs/CONTENT.md).
- Choosing a prompt: start with [examples](docs/EXAMPLES.md).
- Improving a guide: follow [contribution guidance](CONTRIBUTING.md).

## Report an installation problem

Include the OCI Atlas version, client name/version, operating system, installation route, and sanitized error. Explain the step you expected to complete and what happened instead. Use the installation issue template.

## Suggest a knowledge correction

Link the affected guide and section, describe the correction, and include the relevant official Oracle documentation. Distinguish a service change from a wording improvement. Use the knowledge correction template.

## Share only the context needed

Remove customer identifiers, tenancy/resource OCIDs, private endpoints, and sensitive output before posting publicly. Keep passwords, tokens, private keys, wallets, configuration files, and customer data out of issues. For an actual OCI service incident or account-access issue, use your organization's support process or Oracle Support.
